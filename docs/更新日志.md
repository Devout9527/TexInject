## 1.5.4（未发版）

### 更新内容

- **「扩展」页只留两个**：Cookie 登录、相机穿墙。NBT 编辑器、设置耐久、
  杀戮光环那一批实测要么没效果、要么掉帧，UI 和 native 一起撤了 —— 留着只会
  让人以为坏了。
  - **Cookie 登录**：多账号免密切换。左边是功能总开关，右边「悬浮」把窗口
    摆到屏幕上，两者独立。
  - **相机穿墙**：hook 相机避让，镜头不再被方块顶回来。
- **下载捕获 / 相机穿墙开关会记住状态**：以前重进面板开关又跳回「关」，其实 native
  还开着。现在用 SharedPreferences 记住上次设置，重进面板按记忆显示。
- **修防录屏一直不生效**：面板刚挂上那一下就去给图层打「跳过截屏」标记，可窗口还没真正
  上屏，拿不到 SurfaceControl，每次都失败（日志里 `skip-screenshot=false ok=false`）。
  现在会等窗口真正上屏再打；同时多试一条 `getRootSurfaceControl()` 的取法，方法名不
  同的机型也有兜底。开启后模块界面不出现在截屏/录屏里，游戏画面照常。
- **修「快捷键」页点 ⚙ 再返回会跳回列表顶部**：进配置页时整个列表被销毁重建，滚动位置
  归零。现在记住位置，返回时接着原来的地方。切分类、刷新模块后也不会跳回顶部。
- **不再自动装 hook**：以前 so 一加载就装 LocalPlayer hook，时机卡在 mapping 刚结束
  那一瞬，出事就是整个游戏闪退。现在只在真正需要的时候装。
- **修复「导出下载资源」下到一半就停**：之前只有 `open` / `stat` / `access` 这一路
  跟着重定向到外部目录，`rename` / `mkdir` / `opendir` / `truncate` / `unlink` 还走
  老路。下载器把分片从 `temp/` 搬到正式目录时，源文件在内部存储里根本不存在，
  一检查就停。现在这些一起跟着走。
- **修复「扩展」页点进去直接崩**（`Vertically scrollable component was measured with
  an infinity maximum height constraints`）：页面自己已经在滚了，外面又给它套了一层
  `verticalScroll`，Compose 拿到无限高约束就抛异常。
- **修复 3.10 / 3.10.5 下 Python 脚本一调就报 `exec failed`**：游戏把 opcode 表打乱了，
  标准 Python 字节码直接喂进去会跑到别的指令上。现在模块内置一份私有 CPython 2.7.13，
  只负责编译，编完按游戏那张表换 opcode，再交给游戏自己的 marshal 读入、`PyEval_EvalCode`
  执行 —— 执行时机和游戏自己跑脚本一样，在本地玩家 tick 上。被拦的 `PyRun_StringFlags`
  那条路完全不碰。3.9.15 不受影响，还是原来的走法。
  - 脚本放 `Android/data/com.netease.x19/files/netease/`（可以建子目录），
    「脚本」页点 ▶ 就执行，文件名和目录 native 直接读，不用在 Kotlin 里拼源码。

### 提交内容

- `game/GameApi.*` 缩到只剩两个入口：`cameraClip`（`hook::Install` 把
  `CameraAvoidanceSystem_tick` 跳到空函数）和 `SetHandDamage`（读写 `ItemStack+32`
  那个 int）。自动工具 / 背包整理 / 物品编辑器 / 夜视那套连同 20Hz tick 线程、
  `GameMode` / `Supplies` / `MobEffectInstance` 的调用一起删了。
- `SetHandDamage` 不再拒绝负数 —— 游戏里没损耗的物品就是 `-32767`，
  之前 `Value < 0` 直接返回 false 是错的。
- `native-lib.cpp`：JNI 只剩 `gameFeature` / `gameFeatureOn` / `gameAttach` /
  `gameHandDamage` / `gameSetDamage`，前四个都会先 `ensureGameBase()`
  （`ensureBase` + `game::SetBase`），不需要用户先点连接。
- Kotlin 侧：删 `ui/compose/GameTab.kt`，`catsFor()` 回到固定六项；
  相机穿墙 / 设置耐久改成 `ExtensionTab.kt` 里的 `ToggleRow` / `ActionRow`。
- `Panel.kt`：`"扩展"` / `"游戏"` 两个分支不再外套 `Column(verticalScroll)` ——
  页面内部已经是滚动容器，套两层就是「无限高约束套无限高约束」，Compose 直接抛
  `IllegalStateException`。
- `python/`：CPython 2.7.13 编译器子集（107 个 .c），编成静态库
  `pyloader_python27_compiler`，只做编译；和游戏解释器之间只传 marshal 字节流。
- `python/Python3105Bytecode.h`：标准 opcode → 3.10.5 游戏 opcode 的映射表
  （游戏把 opcode 表打乱了，不换就会执行到别的指令上）。
- `common/`：ARM64 特征扫描 + 33 条签名规则 + 地址发布（`Signatures.inc` 由
  `tools/signatures.json` 生成，没有硬编码 RVA）；`FunctionsAddress` 改名
  `PyFunctionsAddress`，避免和 `tp/FunctionsAddress` 撞名。
- `scripts/PythonScriptAbi3105.h`：ABI 见证校验 —— 除了签名唯一性，还反汇编核对
  6 处 call-site 的 `bl` 目标、比对 506 字节的 opcode dispatch 表。
- `scripts/ScriptRuntime.cpp`：后台编译队列、世界代次、GIL 配对、错误归一化。
- `scripts/PyHost.cpp`：`dl_iterate_phdr` 采映像、pipe 读内存、Player tick hook
  （改用我们的 `hook::Install`，原函数照常执行；`+0x1998` 字段和 `Actor::client`
  getter 双向确认过才认为拿到了本地玩家）。
- `native-lib.cpp`：`runPythonFile` 在 3.10.5 上走新加载器并等回执（最长 60 秒），
  3.9 落回原来的 `PyRun_StringFlags`；新增 `pyInit` / `pyReady` / `pyStart` / `pyStatus`。
- `PyLoaderUi.runScript`：不再拼 `exec(compile(...))` 字符串，直接调
  `NativeCore.runPythonFile`。
- `trace/IoTrace.cpp`：`redirect` 拆成 `redirectInto(path, buf, size)`，原来那份
  thread_local 单缓冲留给单路径调用；`rename` 改用两个栈上缓冲 —— 共用一份会变成
  `rename(a, a)`。`lstat` / `faccessat` / `opendir` / `mkdir` / `unlink` / `rmdir` /
  `truncate` / `rename` 补上 `redirect`（原来 14 个 hook 里只有 9 个有）。
  `ensureParents` 改走 `real_mkdir`，否则 `hook_mkdir → redirect → ensureParents →
  mkdir` 会无限递归。
- 3.9.15 不用改：它的 `PyRun_StringFlags`（`+0x123586A4`）编译后调 `+0x122BA940`，
  那个函数先读全局 int `+0x1351EE70`，非 0 才打「exec failed」返回 NULL ——
  `setExecLocked(false)` 写 0 就放行。3.10 把 flag 判断删掉、换成无条件拦截，
  老的写法才彻底失效，这也是为什么 3.10 必须打指令 patch。
  另外 3.9.15 的 so 里根本没有 `SCRIPT_SEC` 字符串，那套日志是 3.10 才加的。

## 1.5.3

### 更新内容

- **新增「扩展」分类**，Cookie 登录和 NBT 编辑器都搬到这里。
  - Cookie 登录从「设置」页挪过来，一个文件一条 cookie，用法不变。
  - **NBT 编辑器**：把 `.snbt` / `.txt` 丢进
    `Android/data/<包名>/files/pack_netease/nbt/`，面板里就能打开、改值、写回。
    编辑只改数字正文，`1b` / `2L` / `1.5f` 这些类型后缀原样保留 —— 大多数同类工具
    存一次就把 byte 变成 int，这里不会。
- **3.10 及以上不再显示「脚本」页**。3.10.5 的 Python 引擎整体换过，老的地址全部
  失效，留一个点不开的页面只会让人以为坏了。
- **扩展功能支持快捷键**。每个扩展右边可以绑一个键（音量键 / 返回键 / F1~F4 等）；
  按下这个键，屏幕上会摆出一个悬浮开关，**再点一下开关**才真正开/关对应的窗口。
  不直接执行是为了不误触 —— 音量键本来就在手边。
- **防录屏改成每次进游戏都是关闭的**，不再记忆上次的开关。开了以后录屏里看不到
  模块界面，出问题时很难排查，所以每次启动都自己决定。

### 提交内容

- 分类从固定 `listOf(...)` 改成 `catsFor()`，按 `GamePaths.version` 判断是否 3.10+；
  面板存的是分类**名字**而不是下标（旧版存过 `cat` 整数，读不到就回落到第一项），
  免得少一页导致下标整体错位。
- 新增 `nbt/Snbt.kt`：SNBT 解析 + 序列化。语法与 Orange 的 `NbtParser` 对齐
  （`{k:v}` / `[v]` / 带转义字符串 / 裸串 / `b s L f d` 后缀），但把值的原始文本和
  后缀一起留住 —— Orange 那边 `Serialize()` 用 `%g` 且不写后缀，往返会丢类型。
- 新增 `ui/compose/ExtensionTab.kt`：扩展页 + NBT 编辑器（选文件、面包屑导航、
  点容器进下一层、点标量弹 `InputDialog` 改值、保存写回原文件）。
- `Panel.kt`：`selected` 从 `Int` 改成分类名，`when` 分支相应改写；设置页不再放
  Cookie 入口。
- 新增 `ExtHotkeys.kt`：扩展功能快捷键。`Activity.dispatchKeyEvent` 之前项目里一处
  都没拦过（现有「快捷键」是给 Python/MCP 用的，按键由脚本侧读配置），
  这里补了 hook + 绑定存储（SP `texinject_ext_hotkey`）+ 状态表。
  命中快捷键只摆出悬浮开关（复用 `FeatureHotkeys`），点开关才执行，
  避免音量键之类的误触。
- 新增 `ui/FloatingHost.kt`：可拖动的 Dialog 容器（不需要悬浮窗权限），
  给 NBT 编辑器 / Cookie 登录做独立窗口用。
- 版本号 `versionCode 152 → 153`、`versionName 1.5.2 → 1.5.3`。

## 1.5.2

### 更新内容

- **新增「清理实体」（材质替换页）**。换了材质，盔甲、武器、实体模型还是老样子或者错乱 ——
  那不是贴图没换成功，是资源包里那些实体定义还写死着旧贴图路径。点一下「清理实体」，
  把这些定义清掉，实体退回引擎默认外观，材质才盖得上去。
  删掉的文件全部进备份，点「恢复官方」原样还回来，随时可逆。
- **只删定义，不删贴图**：`textures`、`sounds`、`ui`、`font` 底下一律不碰；也不按文件名匹配
  （有些同类做法会按 `sword` / `armor` 这种关键字删，会把材质包自带的武器护甲贴图一起删掉，
  这里不做）。

### 提交内容

- 新增 `EntityKiller.kt`（思路来自 SiyoX 的 `EntityKillerManager`，砍掉常驻 `FileObserver`
  和 5 秒巡检 —— 游戏运行期间不会再往包里写实体定义，点按钮时扫一遍就够）。
  命中目录：`attachables` / `attachable` / `animations` / `animation_controllers` /
  `render_controllers` / `entity`；`entity` 若位于 `textures` / `sounds` / `ui` / `font`
  之下则跳过。目录里有本次注入的文件时改为逐层删，不会连带删掉用户自己的模型。
- `PackInjector.killEntities()`：独立入口，不挂进 `inject()` 流程。删之前走 `recordOriginal`
  做硬链接快照 + 记索引，`folder_md5.json` 同步剔除已删条目，`restore()` 的 `copyTree`
  会自动把文件还回去。
- `TexInjector.killEntities()` + 材质页按钮「清理实体」（`GamePaths.isTestBuild` 时隐藏）。
- 启动延迟 `OVERLAY_DELAY_MS` 6 秒 → 8 秒（注释里写的 7.5 秒早就和常量对不上了，一并改正）。
- 版本号 `versionCode 151 → 152`、`versionName 1.5.1 → 1.5.2`。
- 删掉面板开合时的窗口焦点切换：`PanelOverlay` 里的 `setPanelFocusable` 调用，以及
  `OverlayManager.setPanelFocusable` / `setImeEditing` 两个函数。输入早就改成弹独立
  `InputDialog` 了，这两条是死代码 —— 留着只会让每次开关面板都给游戏主窗口发一对
  `FocusEvent(hasFocus)`，而 `FocusEvent` 超时正是 ANR 报的那类事件。

## 1.5.1

### 更新内容

- **支持游戏 3.10.5**。脚本（`.py`）与 Python 材质补丁在这版恢复可用；之前 3.10
  只能跑 Java 层功能。面板「模块说明」里的适配版本号一并更新为
  3.9.15 / 3.10.0 / 3.10.5。
- **注入方式从三选砍成二选**：只剩「官方包 / 镜像目录」，「自动」去掉 —— 自动那条
  路本质是「镜像装得上就用镜像」，失败表现和成功表现都不确定，留着只会让人猜。
  SP 里存过的 0（自动）读出来按官方包处理。
- **二选挪进开发者模式**（连点标题 3 下开启）。普通用户只看得到
  「注入资源 / 恢复官方 / 替换视频 / 恢复视频 / 重启游戏」，注入一律走官方包
  + 维护 `folder_md5.json`，不会再踩镜像目录装不上的坑。开发模式下仍可选
  官方包 / 镜像目录。

### 提交内容

- `561a1ad` 适配游戏 3.10.5。
  - 3.10.5 的 Python 引擎区相对 3.10.0 整体平移 `+0x2FD8`，5 个函数逐条指令比对确认；
    新增 `ADDR_3105` 表（`setExecLocked` 仍无 accessor，保持 0）。
  - 地址表选择改为三级：游戏 `versionName` 前缀 → build-id → 首指令指纹（`addr[1..5]`
    处前 8 字节）。任何一关对不上就零化地址表，退回 Java 层功能，而不是跳野地址崩掉。
  - 三张表在三个 so 上实测互斥：3.9 表 5/5、3.10.0 表 5/5、3.10.5 表 5/5，交叉均为 0/5。
- `2479940` 注入方式三选收进开发者模式：面板只在 `DevMode.enabled` 时渲染三选；
  `TexInjector.run` 在开发模式关着时忽略历史选择强制官方包；启动早期不再为镜像做
  `configure`。
- 去掉 `MODE_AUTO`：`ResourceMount.mode()` 只返回官方包 / 镜像目录，存过的 0 归一化为
  官方包；`TexInjector.run` 删掉 AUTO 分支，镜像失败仍然报错取消。
- 版本号 `versionCode 150 → 151`、`versionName 1.5.0 → 1.5.1`；面板与 `README.txt`
  的适配版本号文案同步。

## 1.5.0

### 更新内容

- 材质注入不再只有「解压覆盖官方包」一条路：能映射时把材质写进
  `pack_netease/active`，游戏照样读官方包目录，官方包一个字节都不动；
  「恢复官方」清空镜像目录即还原。装不上映射时自动退回官方包。
- 修「目录映射」报「没找到目标包」：`/data/user/0/...` 与 `/data/data/...`
  是同一目录的两种写法，`canonicalPath` 会互相替换，现在两边都比一遍。

### 提交内容

- `4249795` I/O 追踪扩容：`kRingSize` 4096→16384、`kPathMax` 160→320（超长路径给
  kind 打 `0x8000`），记录 `fopen` mode / `open` flags，符号从 5 个扩到 17 个
  （`opendir`/`mkdir`/`unlink`/`rename`/`rmdir`/`truncate`/`open64`/`openat64`/
  `__openat`/`fopen64` 等），dump 头部写 hooked / missing 清单。
- `5ed8d86` PLT/GOT hook 基础设施（`app/src/main/cpp/plt/`）+ 文件 I/O 追踪。
- `0ebe8ba` 接入伪自定义目录（`app/src/main/cpp/mount/`）：JNI `mountConfigure` /
  `mountInstall` / `mountStatus`，Kotlin `ResourceMount`，`waitForMinecraft` 里在
  `PendingInstallation()` 时安装。改造三处：别名后缀与物理目录改为运行期参数
  （3.9 / 3.10 通用）；缺文件回退读官方包；`Plt::replace` 先认当前 GOT 槽值再
  `dlsym`，让 I/O 追踪能包住 mount。
- `0098283` 修映射别名：`suffixOf` 两种 base 都试，`findTarget` 兜底挑 `textures`
  存在且 mtime 最新的 FirstPatch。
- `f5d8f58` 注入自动选方式：`injectToMirror`（跳过 manifest / pack_manifest /
  folder_md5，size 相同即跳过）。
- `74577ab` 注入方式给三选：自动 / 官方包 / 镜像目录，存 SP `texinject_mount/mode`，
  默认自动；选镜像但装不上就报错取消注入，不静默改写官方包。

## 皮肤替换

「扩展」页多了皮肤替换。换的是**槽位**——用你现在这个皮肤的名字，显示另一个皮肤的样子。

### 怎么用

1. 扩展 → 皮肤替换
2. 选账号（UID）。选完会自动带出这个账号正在穿的皮肤当槽位，也可以手动点别的
3. 选一个想显示的外观
4. 备份并替换

### 支持的皮肤

游戏里皮肤分两类，都能互相换：

- **4D**：资源是 `.zip`，带骨骼模型（`is_pack: true`）
- **照片**：资源是单张 `.png` 贴图（`is_pack: false`）

同类互换只覆盖资源文件，记录不动。
跨类型（照片 ↔ 4D）会连记录一起改：把 `path` 的后缀和 `is_pack` 跟着来源改，名字、标语、稀有度仍然是你自己那条。

> 照片改 4D 后**需要重启游戏**才生效。

### 安全

- 覆盖前一定先备份到 `files/TexInject/Backup/skin/<item_id>/`，备份失败就整个放弃
- 「还原这个槽位」随时退回原始状态，「全部还原」一次全退
- 备份保留的是**最初那份**，连换几次也能回到起点

### 注意

改皮肤有可能导致进不去世界。真进不去了，用「还原这个槽位」退回去即可。

## 其他

- **扩展页可以滚动了**：以前内容超出右栏就看不到，现在能滑
- **Cookie 登录挪到设置页**：扩展页只留工具入口，入口不再重复
